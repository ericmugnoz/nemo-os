Nemo OS

Sistema operativo para Raspberry Pi 4 — escrito desde cero

Qué estás viendo

Esta pagina la dibuja el visor de HTML de Nemo OS: un programa en Lua (visor.lua) que lee un archivo .html del disco y lo pinta con las fuentes proporcionales del sistema (DejaVu, con antialiasing). No es un navegador: no hay red por debajo, ni JavaScript. Es una forma de escribir documentos y pantallas vistosas para el propio sistema, con una herramienta que ya conoces.

Lo que sabe hacer

  • Encabezados a distintos tamaños, texto grande y pequeño, y tres familias: sans, serif y mono
  • Negrita, cursiva, subrayado y codigo monoespaciado, con acentos: canción, año, ¿qué?
  • Listas con vinetas y numeradas:
    1. anidadas
    2. con su propio sangrado
  • Colores por nombre, en hexadecimal o con rgb()
  • Fondos de bloque, como esta caja blanca, y de texto como este aviso
  • Alineacion a la izquierda, al centro y a la derecha
  • Imagenes en formato .nimg (el del sistema)
  • Enlaces entre páginas — pulsa este para ver la ayuda
  • Tablas, y documentos en Markdown
  • Páginas con comportamiento: botones, contadores, relojes — con <script type="text/lua">
Una cita al margen, con su barra lateral, para textos que quieres destacar.

Texto preformateado

  run visor.lua bienvenida.html
  run visor.lua DOCUMENTOS:ayuda_html.html

Controles: rueda del raton y flechas para desplazarte, clic en un enlace para seguirlo, Retroceso para volver, + y - para el zoom, Esc para cerrar.
